🌟 Projetos em Destaque

🏢 Room Reservation System (Back-end) & (Front-end)

Sistema corporativo completo de gestão de salas, construído sob o paradigma Cloud-Native e Event-Driven Architecture (EDA).

Arquitetura (Back-end): Ecossistema de 8 microsserviços independentes (Gateway, Registry, User, Room, Booking, Notification, Audit, Suggestion) em Java 17 e Spring Boot 3.

Mensageria & Engenharia de Dados: Abordagem Database-per-Service com PostgreSQL isolados. Comunicação assíncrona tolerante a falhas via RabbitMQ (volátil) e Apache Kafka (persistente para auditoria). Caching em memória com Redis.

Engenharia Front-end: SPA reativa em Angular e RxJS. Implementação avançada de WebFlux e Server-Sent Events (SSE) com estratégia anti-buffering para notificações em tempo real.

Segurança & DevOps: Autenticação stateless (JWT) e OAuth2 Híbrida (GitHub). Pipeline de CI/CD via GitHub Actions, Testcontainers para integração e deploys orquestrados via Docker.

🩸 Plus Life - App de Doação de Sangue

Stack: Kotlin, Android Studio, Google Maps API.
