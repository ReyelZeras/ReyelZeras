### 🌟 Projetos em Destaque

#### 🏢 [Room Reservation System](https://github.com/ReyelZeras/room-reservation-system)
[cite_start]Plataforma corporativa para gestão de salas de reunião desenhada com **Arquitetura de Microsserviços** e **Event-Driven Architecture (EDA)**[cite: 147, 148].
* [cite_start]**Back-end:** 8 microsserviços independentes orquestrados por um **API Gateway** e **Service Registry (Eureka)** [cite: 177-184].
* [cite_start]**Mensageria:** Comunicação assíncrona utilizando **RabbitMQ** para notificações e **Apache Kafka** para trilhas de auditoria imutáveis[cite: 169, 170, 213].
* [cite_start]**Resiliência:** Implementação de **Circuit Breaker (Resilience4j)** e estratégia de base de dados isolada (**Database-per-Service**)[cite: 211, 214].
* [cite_start]**Front-end:** Interface reativa em **Angular** com gestão de estado via **RxJS** e notificações em tempo real via **Server-Sent Events (SSE)**[cite: 161, 163, 201].

#### 🩸 [Plus Life - App de Doação de Sangue](https://github.com/ReyelZeras/plus-life-android-app)
Aplicação móvel desenvolvida em **Kotlin** para conectar doadores e hospitais.
* Integração com **Google Maps API** para localização de pontos de doação e gestão de inventário de stock de sangue em tempo real.
