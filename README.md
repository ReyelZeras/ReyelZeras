### 🌟 Projetos em Destaque

#### 🏢 [Room Reservation System](https://github.com/ReyelZeras/room-reservation-system)
Sistema corporativo de gestão de salas desenhado do zero aplicando os mais modernos padrões de arquitetura corporativa.
* **Arquitetura:** Microsserviços orquestrados por API Gateway e Service Registry (Eureka).
* **Mensageria & Resiliência:** RabbitMQ e Kafka para fluxos assíncronos (e-mails/auditoria) e Circuit Breakers (Resilience4j). Banco de dados isolado (Database-per-Service).
* **Front-end:** SPA reativa em Angular com gestão de estado via RxJS e Server-Sent Events (SSE) para notificações em tempo real.

#### 🩸 [Plus Life - App de Doação de Sangue](https://github.com/ReyelZeras/plus-life-android-app)
Aplicativo mobile (TCC) desenvolvido em Kotlin para conectar doadores de sangue a hospitais.
* **Funcionalidades:** Mapeamento em tempo real de hospitais necessitados utilizando a API do Google Maps, ordenação por proximidade e painel informativo.
